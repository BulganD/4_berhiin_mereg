iPhone用「君に」ホーム画面Webアプリ

この一式はTkinter画面をスマホ向けWebアプリに移したものです。抽選結果は元のresult.pyの全組み合わせから移しています。ボタンでも、センサー許可後のスマホのshakeでも同じ抽選になります。

重要: iPhoneの振動センサーをWebアプリで使うにはHTTPSで開く必要があります。また、最初にボタンを押してセンサー利用を許可してください。Webアプリをホーム画面に追加した後は、初回読み込みで保存されたファイルを使ってオフラインでも起動できます。

Windows PCから使う手順:
1. このフォルダーの内容をHTTPS対応の静的Webホスティング先へアップロードします（例: GitHub Pages、Cloudflare Pages）。
2. iPhoneのSafariで表示されたHTTPS URLを開きます。
3. 「共有」→「ホーム画面に追加」を選びます。
4. ホーム画面から開き、最初に「将来を知ろう」を一度押して、モーションセンサーの許可を選びます。
5. 以後、ボタンまたはスマホを振って抽選します。

App Storeのネイティブアプリではありません。Windowsだけで準備でき、Mac/Xcodeは不要です。Safariの仕様により、センサー許可が拒否された場合はボタンを使ってください。
